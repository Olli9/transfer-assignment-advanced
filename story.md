# The History of Git

In the spring of 2005, the Linux kernel community suddenly found itself without the version-control system it had been using. Linus Torvalds, who had created Linux, decided to build a new system that could handle the enormous number of changes made by many developers while remaining fast and distributed. Within days, the first version of Git began to take shape.

Git was designed around a simple but powerful idea: every developer could have a complete copy of the repository and its history. Instead of depending on a central server for every operation, developers could create commits, compare changes, and work on branches locally. This made experimenting with new ideas much easier and helped solve many of the collaboration and performance problems faced by large open-source projects.
